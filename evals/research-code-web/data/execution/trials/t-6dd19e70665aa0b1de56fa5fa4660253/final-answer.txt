## Contrast: explicit `proxy=` argument

The gate at :685 only controls *environment* proxies. If `proxy` is non-None, `_get_proxy_map` takes the `else` branch (:249–251) and returns `{"all://": Proxy(...)}` **regardless of `transport`/`allow_env_proxies`**. The mounts comprehension (:697–709) then builds one catch-all mount via `_init_proxy_transport` (:750–757). Because the normalized pattern `"all://"` has empty scheme, host, and port, `URLPattern.matches` (:192–203, `httpx/_utils.py`) matches every URL, and priority sorting (`URLPattern.priority`, :205–217: port first, then longest host, then longest scheme) places bare `all://` last — where it still matches anything unmatched earlier. So an explicit proxy *does* bypass a supplied custom transport: requests resolve to the freshly constructed proxy transport, not the custom one.

## Explicit mounts and `None` values

Explicit `mounts` overwrite same-key entries via `dict.update` (:712–713). A `None` value is meaningful: `_transport_for_url` returns `self._transport if transport is None else transport` (:767) — a matched `None` mount explicitly selects the client's default transport (here, the custom transport), acting as a "no proxy here" opt-out that outranks broader proxy mounts by specificity ordering. With no mounts at all (the scenario in question), selection simply yields `self._transport` (:769).
