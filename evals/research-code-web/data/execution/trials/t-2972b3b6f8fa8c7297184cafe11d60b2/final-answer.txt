## Implementation ordering and child-context creation

`Group.invoke`, `src/click/core.py:2052-2118`:

- **No subcommand:** with no protected args (2058) and `invoke_without_command` true (2059), it enters `with ctx:` and calls `super().invoke(ctx)` (2063-2064). `Command.invoke` (1432-1446) ultimately runs the group callback via `ctx.invoke(self.callback, **ctx.params)` (1445-1446). `ctx.invoked_subcommand` is never assigned on this path, so it stays `None` — exactly the condition the test checks at line 283. The result is wrapped by `_process_result([] if self.chain else rv)` (2065).
