### 2. Recursion and Returning Remaining Arguments

`Find` uses an inner recursive closure, `innerfind` (lines 758–772):
```go
innerfind = func(c *Command, innerArgs []string) (*Command, []string)
```

1. **Stripping flags to identify subcommands:** 
   At each step, `innerfind` calls `stripFlags(innerArgs, c)` (lines 674–710) to obtain non-flag arguments (`argsWOflags`). `stripFlags` merges persistent flags (`c.mergePersistentFlags()`), looks up flags to distinguish flag names from flag values, handles `--` as the flag terminator, and skips flags and values (including space-separated flag arguments without defaults via `hasNoOptDefVal` / `shortHasNoOptDefVal`).
2. **Base case:** 
   If `len(argsWOflags) == 0`, recursion stops and returns `(c, innerArgs)` (lines 762–763).
3. **Subcommand lookup and recursive descent:** 
   The first non-flag argument `nextSubCmd := argsWOflags[0]` is looked up using `cmd := c.findNext(nextSubCmd)` (lines 765–767).
   * If a child matches (`cmd != nil`), it recurses on that child command:
     ```go
     return innerfind(cmd, c.argsMinusFirstX(innerArgs, nextSubCmd))
     ```
     (line 769).
   * `argsMinusFirstX(innerArgs, nextSubCmd)` (lines 715–748) removes **only the first occurrence** of `nextSubCmd` from the arguments list while preserving all flags, flag values, and any later identical tokens.
   * If no child matches (`cmd == nil`), recursion stops and returns the current node and its unconsumed arguments: `return c, innerArgs` (line 771).
4. **Final return:** 
   `commandFound, a := innerfind(c, args)` (line 774).
   * If `commandFound.Args == nil`, legacy arg validation runs: `return commandFound, a, legacyArgs(commandFound, stripFlags(a, commandFound))` (lines 775–777).
   * Otherwise, it returns `(commandFound, a, nil)` (line 778).
   The returned slice `a` retains all flag arguments and unconsumed arguments for subsequent parsing and execution (e.g., in `ExecuteC` / `cmd.execute(flags)`, lines 1123, 1148).

### 3. Name and Alias Matching

Subcommand resolution is implemented in `(*Command).findNext(next string) *Command` (lines 798–817):
1. **Name and alias lookup:**
   For each child `cmd` in `c.commands` (lines 800–804):
   ```go
   if commandNameMatches(cmd.Name(), next) || cmd.HasAlias(next) {
       cmd.commandCalledAs.name = next
       return cmd
   }
   ```
2. **Matching semantics:**
   * `commandNameMatches(s, t)` (lines 1928–1934): When global configuration `EnableCaseInsensitive` is true, it performs a case-insensitive check via `strings.EqualFold(s, t)`; otherwise, it checks exact string equality `s == t`.
   * `(*Command).HasAlias(s)` (lines 1551–1558): Iterates over `c.Aliases` and returns `true` if `commandNameMatches(a, s)` matches any alias.
3. If an exact name or alias matches, `cmd.commandCalledAs.name` is updated to `next` and the matching `*Command` is returned immediately without checking further children.

### 4. Behavior When Prefix Matching Is Enabled but Multiple Children Match

When no exact name or alias match is found, `findNext` evaluates prefix matching if globally enabled:
1. **Prefix collection:**
   ```go
   if EnablePrefixMatching && cmd.hasNameOrAliasPrefix(next) {
       matches = append(matches, cmd)
   }
   ```
   (lines 805–807). `(*Command).hasNameOrAliasPrefix(prefix)` (lines 1571–1583) checks whether `c.Name()` or any alias in `c.Aliases` begins with `prefix` using `strings.HasPrefix`.
2. **Single prefix match:**
   If exactly one child matches (`len(matches) == 1`), `matches[0]` is returned (lines 810–814).
3. **Multiple matches (`len(matches) > 1`):**
   * If more than one child matches the prefix, `findNext` **does not** pick any command; it bypasses the `len(matches) == 1` check and executes `return nil` (line 816).
   * Because `findNext` returns `nil`, `innerfind` fails the `if cmd != nil` condition (lines 768–771) and returns `c, innerArgs`.
   * **Result:** Downward traversal halts at the parent command `c`. `nextSubCmd` is treated as a positional/non-subcommand argument rather than a subcommand invocation, and `Find` returns the parent command with the remaining arguments intact (no ambiguity error is returned directly by `Find`).
