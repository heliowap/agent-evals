### 2. How Permissions are Merged in Order

* In `packages/opencode/src/session/llm/request.ts:213`, permissions are merged by calling:
  ```ts
  Permission.merge(input.agent.permission, input.permission ?? [])
  ```
* In `packages/opencode/src/permission/index.ts:200–202`:
  ```ts
  export function merge(...rulesets: PermissionV1.Ruleset[]): PermissionV1.Rule[] {
    return rulesets.flat()
  }
  ```
* Order of elements:
  1. The agent's base ruleset (`input.agent.permission`) comes first.
  2. The session/request ruleset (`input.permission ?? []`) is appended afterwards.
  Because the downstream rule evaluator traverses the array from the end (`findLast`), rules appended later (session/request permissions) override earlier matching rules (agent permissions).

### 3. Which Message-Toggle Values Exclude a Tool


* **Excluded value:** Only the explicit boolean value `false` (`input.user.tools?.[k] === false`) excludes a tool.
* Values of `true`, `undefined` (omitted), or other truthy/non-`false` values do not exclude the tool via the message toggle.

### 4. How a Permission Rule is Chosen and Used to Disable a Tool

The logic resides in `Permission.disabled` (`packages/opencode/src/permission/index.ts:204–214`):

1. **Rule Selection:**
   ```ts
   const rule = ruleset.findLast((rule) => Wildcard.match(permission, rule.permission))
   ```
   The ruleset is searched in reverse order (`findLast`) for the last rule whose `rule.permission` matches the tool's normalized permission category using `Wildcard.match`.
2. **Disabling Decision:**
   ```ts
   return rule?.pattern === "*" && rule.action === "deny"
   ```
   A tool is marked disabled if and only if a matching rule exists with:
   * `pattern === "*"` (a blanket wildcard covering all targets/paths)
   * `action === "deny"` (a hard denial; `"allow"` or `"ask"` do not disable the tool at request preparation time)
3. **Filtering:**
   Back in `resolveTools` (`packages/opencode/src/session/llm/request.ts:215`), if `disabled.has(k)`, the tool is stripped from the returned dictionary.
