### 2. Execution Order: Input Parsing vs. Transformation

Because `.transform(tx)` constructs `pipe(this, transform(tx))`:
* **Input Parsing Occurs First**: The incoming input is processed by the upstream schema (`this`, the string schema) to perform type checking, string validations, checks, etc.
* **Transformation Occurs Second**: Once the upstream stage passes, the payload is handed to the `ZodTransform` stage. Its parsing logic is executed in `packages/zod/src/v4/classic/schemas.ts:2257-2287`:
  1. Direction check: If parsing backwards (`_ctx.direction === "backward"`), it throws `new core.$ZodEncodeError(inst.constructor.name)` (lines 2258–2260).

### 3. Issues Stopping the Pipe and Issue-Code Exceptions

* In pipeline evaluation across steps:

  * In Zod's pipeline semantics, execution along a pipe halts if an unrecoverable/fatal issue occurs or if issues accumulate that prevent continuing down the pipe.
