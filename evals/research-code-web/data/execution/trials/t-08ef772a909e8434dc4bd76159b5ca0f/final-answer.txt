The comment at `command.go:755–756` states its role: "Find the target command given the args and command tree. Meant to be run on the highest node. Only searches down."

**How the recursion works (757–779).** `Find` defines a nested function `innerfind(c *Command, innerArgs []string) (*Command, []string)` and calls it on the root command at line 774. At each level it:
1. Calls `stripFlags(innerArgs, c)` (`command.go:674–710`) — this is where flags are set aside: flag tokens (and their values, including anything after `--`) are not treated as command names; only non-dash tokens are collected into `commands` (704–705). Flag args are therefore retained in `innerArgs` rather than consumed.
2. If no flagless args remain, returns the current command with the untouched args (762–764).
3. Otherwise takes the first flagless token `nextSubCmd` (765) and resolves it against children with `c.findNext(nextSubCmd)` (767).
4. On a match, recurses into that child, but first removes the matched token from the args via `c.argsMinusFirstX(innerArgs, nextSubCmd)` (`command.go:715–748`), which deletes only the first exact occurrence `x` while skipping flag values (726–735), so flags survive into later levels.
5. On no match, returns the current command with the full remaining args (771) — this is how leftover arguments accumulate for later flag/argument parsing.

After recursion, `Find` validates arg counts: if the located command has no `Args` validator it applies `legacyArgs` (775–776), otherwise returns nil error (777–778).

**Name/alias matching — `findNext` (`command.go:798–817`).** It iterates over `c.commands`; a child matches if `commandNameMatches(cmd.Name(), next) || cmd.HasAlias(next)` (line 801). On an exact name/alias hit it records `cmd.commandCalledAs.name = next` (802, so `CalledAs()`, lines 1560–1567, reports how it was invoked) and returns immediately. Separately, if global `EnablePrefixMatching` is on (`cobra.go:46,55`), children whose name or alias merely starts with the token are collected via `hasNameOrAliasPrefix` (805–806).

**Prefix ambiguity.** If exactly one prefix child matched, it is returned (`matches[0]`, 810–813, with a gosec note for the bounds check). If **zero or more than one** child prefix-matches, `findNext` returns `nil` (816) — i.e., among multiple prefix matches the call deliberately fails, and `innerfind` then treats the token as a leftover argument rather than a command (771). `hasNameOrAliasPrefix` (`command.go:1571–1583`) matches the name (1572–1575) then each alias (1576–1581), recording whichever string matched in `commandCalledAs.name`.

**Supporting parsing details.** `stripFlags` (674–710) skips flag `=`-values, short flags in a combined cluster, and everything after `--`; `argsMinusFirstX` (715–748) avoids mistaking a flag's value for the command token (`Loop` with `pos++` at 726–735).
