## DeepSeek native request/response

Source: https://api-docs.deepseek.com/api/create-chat-completion

> reasoning_effort string. Possible values: [none, low, high, max]. Controls the thinking mode toggle and the thinking effort. none disables thinking mode; low / high / max enable thinking mode. The default effort is high.
> max_tokens: The maximum number of tokens that can be generated in the chat completion.
> tool_choice: none means the model will not call any tool and instead generates a message. auto means the model can pick between generating a message or calling one or more tools. none is the default when no tools are present. auto is the default if tools are present.
> reasoning_content: For thinking mode only. The reasoning contents of the assistant message, before the final answer.
> prompt_tokens: It equals prompt_cache_hit_tokens + prompt_cache_miss_tokens.
> cached_tokens: Same as prompt_cache_hit_tokens.
> completion_tokens_details.reasoning_tokens: Tokens generated by the model for reasoning.

The primary page documents nonstreaming JSON chat completion responses and assistant function calls with JSON-string arguments. Thinking defaults enabled.

## GLM native request/preserved reasoning

Source: https://docs.z.ai/api-reference/llm/chat-completion

> reasoning_effort: Controls the model's reasoning effort level, takes effect when thinking is enabled. Default is max, supported by GLM-5.2 and above. For the GLM-5.3 GLM-5.3-FLASH model, only the low / high / max levels are supported.
> thinking.type: GLM-5.3 GLM-5.3-FLASH series can only be enabled, and the thinking depth is controlled by reasoning_effort; default: enabled.
> clear_thinking: false: Retains reasoning_content from prior turns and includes it in the context sent to the model. To enable Preserved Thinking, you must forward the full, unmodified, and correctly ordered historical reasoning_content in messages.

The page documents nonstreaming JSON, function tools, assistant reasoning_content, max_tokens and inclusive prompt/completion usage. Its GLM tool_choice schema permits only auto: the runner removes tools on step eight rather than sending unsupported none. The common thinking envelope requests only type enabled, documented by both providers. Every native historical reasoning_content is preserved unchanged on the client wire. GLM's default clear_thinking may ignore historical reasoning server-side; server-side retention/honoring is UNVERIFIED. No unsupported common clear_thinking field is added to DeepSeek, and no candidate probe is authorized.
