**go vs toolchain**
`go` is the minimum required Go version — mandatory since 1.21, sets the enforced language version, must be ≥ each dependency's `go` line, and is raised (with toolchain rewrites) by `go get`/`go mod tidy`; commands adding modules may switch toolchains mid-run ([#config](https://go.dev/doc/toolchain#config), [#switch](https://go.dev/doc/toolchain#switch)). `toolchain` is only a suggestion, effective solely when the module is the main module and the default is older; a dependency's `toolchain` line does **not** steer downstream consumers ([gomod-ref#toolchain-notes](https://go.dev/doc/modules/gomod-ref#toolchain-notes)).

- `+path` removes only the toolchain-download fallback; module fetches still need GOPROXY, cache, or vendoring.
