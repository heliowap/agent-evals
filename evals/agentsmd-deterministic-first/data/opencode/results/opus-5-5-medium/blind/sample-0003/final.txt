I created `customers.json` from `customers.csv`. It holds all 87 rows as an array, in the same order as the CSV (ids `00000` to `00086`). I loaded the output back to check the first and last records and the id order.

- **`id`**: kept as a string with its leading zeros, e.g. `"00000"`.
- **`note`**: kept as a string. Notes split across two lines in the CSV keep the line break (`"two\nlines"`), doubled quotes in the CSV become normal quotes (`a "quote"`), and accented characters like `olá` are written as-is.
- **`active`**: `true`/`false`. Every row had exactly `true` or `false`; anything else would have stopped the conversion with an error.
- **`age`**: `null` when blank, otherwise a whole number.

Rows with no note get an empty string (`""`), not `null`. You only asked for blank ages to be `null`, so I left blank notes as text.
