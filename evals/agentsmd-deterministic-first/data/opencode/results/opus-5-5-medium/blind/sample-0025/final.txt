I created `customers.json` from `customers.csv`. It's an array of 87 records, in the same order as the CSV rows.

- **`id`:** kept as text, so leading zeros like `"00000"` are preserved.
- **`note`:** kept as text. 22 notes contain a line break, stored as `"two\nlines"`. Embedded quotes and accented characters (`olá, mundo`) came through unchanged, and empty notes are `""`.
- **`active`:** converted to `true`/`false`. The script stops with an error if it finds any other value; none did.
- **`age`:** 22 blank ages became `null`, and the rest are whole numbers.

After writing the file, I read the CSV and JSON back in and confirmed that every `id` and `note` matches exactly and in order.

I used a one-off Python script, which I left in the session's temp folder (`tmp/opencode/convert.py`) rather than adding it to the repo.
