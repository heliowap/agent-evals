**Defect — `parser.py:2`:** `bool(value)` checks truthiness, not valid Boolean strings. Consequently:
- `"false"` incorrectly returns `True`.
- `"invalid"` returns `True` and `""` returns `False`, instead of raising `ValueError`.

**Recommendation:** Explicitly accept only `"true"` → `True` and `"false"` → `False`; raise `ValueError` for everything else. Do not normalize case or whitespace.

Prevent recurrence with regression tests covering both valid strings and rejected inputs: unknown strings, empty strings, uppercase variants, surrounding whitespace, and non-string values.
