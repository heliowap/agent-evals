# Preregistered answer key for round 2

The three cases are Axios, Rust and Requests, with one *Spec* target and one *Standards* target in each case. The hash of this answer key is part of `manifest.json`, generated before the first review call. The excerpts delivered to the models carry the original request, the PR claim, the diff, the context and the rules needed for the analysis, without the results of the reproductions described here.

## Prior scoring rule

Each case will have separate targets for *Spec* and *Standards*. A target only counts when the response identifies the relevant location, the concrete mechanism and the consequence **on the right axis**; file names without explanation, generic suggestions and hypotheses without a mechanism are not enough. Repeating the same finding in a response does not create another point. Valid findings outside the answer key will be classified separately, without retroactively widening the targets. A claim will only be counted as false when it can be refuted by a source or reproduction; whatever remains unverifiable will not be treated as a false positive. Adjudication will be done with shuffled responses and without the model name.
